Lição 1 | A letra Alef

א

Nome: Alef

A primeira letra do alfabeto hebraico é o Alef. No hebraico bíblico, ela representa uma consoante que pode funcionar como suporte para uma vogal.

O hebraico é escrito da direita para a esquerda. Aprender essa direção é um dos primeiros passos para ler os textos bíblicos.
